# appbox

Ref12's small open-source apps.

| App | What it is |
| --- | --- |
| [Medusa](medusa/) | Android app that turns a video link into stone: it captures the video and its subtitles on the phone with yt-dlp, plays it with adjustable subtitle sync, and serves both to web apps on the same phone (first client: LinguaWeave). |

Each app lives in its own folder with its own README, build and release workflow. Licence: see `LICENSE`.
